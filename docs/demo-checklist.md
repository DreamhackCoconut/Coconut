# Coconut demo checklist

## Before demo

- [ ] Appwrite Site deployment works, or local `npm run dev` is ready
- [ ] Reset demo state with `DEMO_MODE=true`
- [ ] Handwoven Coastal Basket is in stock
- [ ] Friday West Coast shared departure is active
- [ ] OR-Tools optimizer is functioning or TypeScript fallback is visible
- [ ] Map renders with attribution
- [ ] Weather is available, cached, or labeled demo
- [ ] Artisan dashboard is populated
- [ ] Browser is clean with no console errors or stale tabs
- [ ] README and docs match the deployed build

## During demo

- [ ] State the remote-island shipping problem
- [ ] Add the basket
- [ ] Show solo vs shared shipping and savings
- [ ] Show Shell Earrings +$0 recommendation
- [ ] Add the earrings
- [ ] Open Operations
- [ ] Optimize the pickup route
- [ ] Explain weather/departure risk
- [ ] Open Artisan intelligence
- [ ] Close with the Coconut pitch

## Canonical state

- Product: Handwoven Coastal Basket
- Companion: Shell Earrings
- Batch: Friday West Coast Batch
- Operations action: Optimize pickup route
- Artisan view: production queue → market opportunity → price guidance
- Closing line: “Coconut makes dozens of tiny island exporters behave like one coordinated logistics network.”
